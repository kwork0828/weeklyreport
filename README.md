# weeklyreport

> **상태: 설계·초안 단계 (main 브랜치에는 결과물 없음)**
> Apps Script 초안은 `claude/weekly-report-automation-546g12` 브랜치에 있고, 실제 스프레드시트에서의 검증은 아직 기록되지 않았습니다.

## 목적

취업컨설팅 **주간업무보고** 작성을 자동화합니다.
매주 상담일지를 내려받아 피벗으로 집계하고, 프로그램 현황·특이사항을 손으로 쓰던 과정을
Google Apps Script로 대체하는 것이 목표입니다.

## 자동화 범위 (브랜치 README 기준)

| 보고 항목 | 자동화 수준 | 비고 |
|---|---|---|
| ① 상담 현황 (기수 × 상담방법 건수표) | 완전 자동 | 상담일지 시트를 읽기만 하고 집계 |
| ② 프로그램 현황 | 부분 자동 | 주간채용알림·취업세미나는 원본 데이터가 없어 수기 유지 |
| ③ 특이사항 – 컨설팅 기업 | 부분 자동 | `잡매칭` 컬럼 기반 초안, 문장 다듬기는 사람 |
| ③ 특이사항 – 신규 취업자 | 부분 자동 | 취업설문과 교육생 명단 대조, 동명이인은 사람이 확인 |
